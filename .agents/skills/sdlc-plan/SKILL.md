# SDLC Planning & Architecture Skill

## Instructions
1. Ingest the specification from `artifacts/spec_issue_{issueNumber}.md`.
2. Propose concrete C# classes, records, interfaces, and minimal API endpoints.
3. Establish the verification matrix across unit, integration (`WebApplicationFactory`), and performance tests.
4. Output the implementation plan to `artifacts/plan_issue_{issueNumber}.md`.
