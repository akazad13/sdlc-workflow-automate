# SDLC Triage & Inception Skill

## Instructions
1. Parse the incoming issue title, description, labels, and customer requirements.
2. Formulate explicit, testable Acceptance Criteria (Given-When-Then or numbered criteria).
3. Identify affected microservices, endpoints, and architectural layers.
4. Output the formalized specification document to `artifacts/spec_issue_{issueNumber}.md`.
